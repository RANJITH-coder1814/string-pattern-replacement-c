# string-pattern-replacement-c
A C program that performs pattern matching and string replacement using fundamental string processing logic without built-in functions.

🔍 String Pattern Matching & Replacement in C

A C program that performs pattern matching and string replacement without using built-in string functions. This project demonstrates manual string processing, pattern searching, and replacement logic using basic C programming concepts.

📌 Project Overview

This project reads:

A main string

A pattern string

A replacement string

It then searches for the pattern inside the main string and replaces it with the given replacement string, generating a new result string.

This project is ideal for:

Beginners learning string manipulation in C

Academic mini-projects

Understanding pattern matching algorithms

✨ Features

Manual pattern matching

Find & Replace functionality

No built-in string functions used

Displays pattern position

Clean and beginner-friendly code

🛠️ Technologies Used

Programming Language: C

Libraries: stdio.h, conio.h

Compiler: VS Code
